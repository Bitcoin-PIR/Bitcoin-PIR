# Payment V1 edge templates

This directory indexes edge source templates. The BAT V2 artifact command does
not render or select them. Use [Production operations](../../../docs/PRODUCTION_OPERATIONS.md)
to select the current workflow; the existing template gate is
[`scripts/payment-v1-deployment-template-gate.mjs`](../../../scripts/payment-v1-deployment-template-gate.mjs).

This README is an index, not another deployment procedure.
