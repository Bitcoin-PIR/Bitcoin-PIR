# Payment V1 templates

This directory contains Payment V1 source templates. Start from
[Production operations](../../docs/PRODUCTION_OPERATIONS.md); the Payment V1
runbooks identify the current artifact, issuer-state, sealed-release, and
activation commands. The subdirectories below are source-template indexes;
current commands remain in the linked runbooks and scripts.

- [`edge/`](edge/README.md): public edge templates.
- [`network/`](network/README.md): network and relay templates.
- [`lightning/`](lightning/README.md): Core Lightning templates.
- [`bat-v2-source-ready/`](bat-v2-source-ready/README.md): preserved source-ready record.
