# Payment V1 network templates

This directory indexes network and directory-relay source templates. Use
[Production operations](../../../docs/PRODUCTION_OPERATIONS.md) to select the
current workflow. The existing directory-relay build entry point is
[`scripts/build-payment-v1-directory-relay.sh`](../../../scripts/build-payment-v1-directory-relay.sh).

The machine-checked template contract also covers relay selection, UFW,
`centralized-single-relay`, Namespace teardown, and the publisher ceremony that
must not be run on Hetzner.

This README is an index, not another deployment procedure.
