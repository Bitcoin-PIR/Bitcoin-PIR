# Archived Payment V1 material

This directory keeps retired plans, status snapshots, drill records, migration
notes, review evidence, and the former normative Payment V1 design
(architecture, protocol, directory, persistence, security). These files
describe earlier decisions and runs; they are not operating procedures.

Paid queries now present a designated issuer's cashu/ARC credential on
opcodes `0x08`/`0x09`. The issuer is [`apps/payment-issuer`](../../apps/payment-issuer).
For current commands, use [Production operations](../../PRODUCTION_OPERATIONS.md).
