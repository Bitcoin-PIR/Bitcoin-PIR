# Related repositories

This repository holds the wire protocol, database catalog, clients, server,
web application and deployment integration. Related code lives in other
repositories under the [Bitcoin-PIR organization](https://github.com/Bitcoin-PIR):

| Repository | Contents |
|---|---|
| [`Bitcoin-PIR/harmonypir`](https://github.com/Bitcoin-PIR/harmonypir) | HarmonyPIR protocol and client state machine |
| [`Bitcoin-PIR/attested-builder`](https://github.com/Bitcoin-PIR/attested-builder) | Native full-build V2 database and BuildEvidence producer |
| [`Bitcoin-PIR/bhtm`](https://github.com/Bitcoin-PIR/bhtm) | BHTM proof producer |
| [`Bitcoin-PIR/oram`](https://github.com/Bitcoin-PIR/oram) | ORAM implementation |
| [`Bitcoin-PIR/protocol-proofs`](https://github.com/Bitcoin-PIR/protocol-proofs) | EasyCrypt proof of the wire-shape and leakage model |
| [`Bitcoin-PIR/proof-registry`](https://github.com/Bitcoin-PIR/proof-registry) | Generated DB/BHTM/ORAM proof bundles |
| [`Bitcoin-PIR/issuer`](https://github.com/Bitcoin-PIR/issuer) | Credit issuer |
| [`Bitcoin-PIR/playground`](https://github.com/Bitcoin-PIR/playground) | Demos and SDK documentation site (vendors `web/src` and `pir-sdk-wasm`) |
| [`Bitcoin-PIR/whitepaper`](https://github.com/Bitcoin-PIR/whitepaper) | Paper sources and research evaluation |
| [`Bitcoin-PIR/website`](https://github.com/Bitcoin-PIR/website) | Documentation website |
