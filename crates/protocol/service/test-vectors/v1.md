# BitcoinPIR service protocol v1 test vectors

All integers are little-endian. Hex strings use lowercase ASCII without a
prefix. These values are asserted by the Rust tests and are intended for the
native SDK, WASM/Web implementation, and external issuer implementations.

## Provider ID

- operator Ed25519 public key: `01` repeated 32 times
- stable server ID UTF-8: `server-a`
- server ID length prefix: `08000000`
- domain: ASCII `BitcoinPIR/provider-id/v1`
- provider ID:
  `26edf1827d387c09e8e088d33532cf8c88cff7607c9817892159362d98c3361e`

The URL, IP address, client slot, and peer provider are not inputs.

## Service scope

- provider ID: `07` repeated 32 times
- backend: `HarmonyPirV2` (`02`)
- workload: `HarmonyHintBundleV1` (`02`)
- backend protocol version: `2`
- dataset: class `9`
- operation profile: `11`
- entitlement profile: `12`
- canonical encoding:
  `010707070707070707070707070707070707070707070707070707070707070707020202000109000b000c00`
- domain: ASCII `BitcoinPIR/service-scope/v1`
- scope ID:
  `e7234a6b4100c84b3d9d862072caaedd18ef45516bad06db6252f7a2d0352376`

Signed policy, authorization-frame, and paid-receipt vectors will be added
before cross-language Web/issuer integration is declared complete.
